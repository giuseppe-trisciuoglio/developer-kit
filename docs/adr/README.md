# Architecture Decision Records

This directory hosts Architecture Decision Records (ADR) for the Developer Kit.

Each ADR captures one architecturally significant decision: its context, the choice made, the consequences, and the alternatives considered. Decisions are immutable once accepted; superseding decisions are recorded as new ADRs that reference the previous one.
